# 아이패드 점검표 (성공 기준 8~10)

자동 테스트로는 확인할 수 없는 세 가지를 실제 아이패드에서 손으로 확인합니다.
결과 칸에 ○(됨) / ×(안 됨)와 본 것을 적어 알려 주세요. ×가 나온 항목은 그 내용을 바탕으로 고칩니다.

## 준비

배포를 하지 않으므로, **컴퓨터에서 앱을 켜고 같은 와이파이의 아이패드로 접속**합니다.

필요한 것: 컴퓨터(윈도우·맥 모두 가능), [Node.js](https://nodejs.org) 18 이상, 이 저장소를 내려받은 폴더.

1. 컴퓨터에서 저장소 폴더를 열고 터미널에 입력합니다.

   ```bash
   npm start
   ```

   `http://localhost:8080`이 출력되면 켜진 것입니다. 점검이 끝날 때까지 이 창을 닫지 않습니다.

2. 컴퓨터의 내부 IP 주소를 확인합니다(예: `192.168.0.12`).
   - 윈도우: 터미널에 `ipconfig` → "IPv4 주소"
   - 맥: 시스템 설정 → Wi-Fi → 연결된 네트워크의 "세부사항" → IP 주소

3. 아이패드를 **같은 와이파이**에 연결하고 Safari 주소창에 `http://<IP 주소>:8080`을 입력합니다
   (예: `http://192.168.0.12:8080`). "집필실" 서재 화면이 나오면 준비 끝입니다.
   처음에는 엔진(약 27MB)을 받느라 몇 초 걸립니다.

접속이 안 되면: 두 기기가 같은 와이파이인지, 컴퓨터 방화벽이 Node.js의 연결을 막지 않았는지 확인합니다.

이 방식의 한계: 주소가 `http://`라서 **공유 시트와 오프라인 실행은 동작하지 않습니다.**
내보내기는 Safari의 "다운로드"로 저장됩니다. 공유 시트·오프라인·홈 화면 설치는 나중에 배포(https)한 뒤 따로 확인해야 합니다.

## 점검 8 — 집필 화면 한글 입력

1. **새 문서**를 누릅니다.
2. 화면 키보드(한글)로 아래 글을 그대로 입력합니다. 줄이 바뀌는 곳에서 return을 누릅니다.

   > 오늘은 아침부터 비가 내렸다. 창밖을 보며 따뜻한 차를 한 잔 마셨다.
   > 받침이 많은 낱말도 써 본다: 닭, 값, 읽다, 앉았다, 넓은, 삶, 꿇었다.
   > 빠르게 쳐도 글자가 깨지지 않는지 본다. 가나다라마바사 아자차카타파하.

3. 이어서 아무 글이나 300자 정도 더 씁니다.

| 확인할 것 | 결과 | 본 것 |
| --- | --- | --- |
| 자모가 풀어지거나(ㅇㅗㄴㅡㄹ) 글자가 빠지지 않는다 | | |
| return을 누르면 새 문단이 생기고 커서가 그리로 간다 | | |
| 쓰기 시작하면 위쪽 도구 막대가 사라진다 | | |
| 글 바깥(좌우 여백)을 누르면 도구 막대가 다시 나온다 | | |
| 쓰는 문단만 또렷하고 나머지는 흐리다 | | |
| 화면 키보드가 떠 있어도 쓰는 줄이 키보드에 가려지지 않는다 | | |
| 입력을 멈추면 몇 초 뒤 위쪽에 "저장됨"이 보인다(도구 막대를 다시 띄워 확인) | | |
| **‹ 서재**로 나갔다가 문서를 다시 열면 글이 그대로다 | | |

## 점검 9 — 편집 화면 입력과 표

1. 점검 8의 문서에서 위쪽 **편집**을 누릅니다. 한글 편집기 화면이 뜹니다.
2. 본문의 아무 곳이나 눌러 커서를 두고, 화면 키보드로 "편집에서 쓴 글"을 입력합니다.
3. 문단 하나를 길게 눌러 선택하고(또는 두 번 눌러 낱말 선택), 도구막대에서 **가**(굵게)를 누르고 줄 간격을 **200 %** 로 바꿉니다.
4. 도구막대의 **표** 단추를 눌러 격자에서 2줄 3칸을 고릅니다.
5. 표의 첫 칸을 눌러 "칸1"을 입력합니다.
6. 위쪽 메뉴 **표 → 줄/칸 추가하기**에서 "아래쪽에 줄 추가하기"를 고르고 **추가**를 누릅니다.
7. 위쪽 **집필**을 눌러 돌아옵니다.

| 확인할 것 | 결과 | 본 것 |
| --- | --- | --- |
| 편집 화면에 문서가 쪽 모양으로 보인다(빈 종이가 아니다) | | |
| 본문을 누르면 화면 키보드가 올라오고 한글이 입력된다 | | |
| 손가락으로 글자를 선택할 수 있다 | | |
| 굵게와 줄 간격이 화면에 반영된다 | | |
| 표가 만들어지고 칸 안에 한글이 입력된다 | | |
| 줄 추가 뒤 표가 3줄이 된다 | | |
| 메뉴·단추가 손가락으로 누르기에 너무 작지 않다 | | |
| 집필로 돌아오면 "편집에서 쓴 글"이 보이고, 표 자리에 "▦ 표 3×3" 표시가 있다 | | |

화면 키보드로 입력이 안 되면, 블루투스 키보드가 있을 때 그것으로도 한 번 해 보고 결과를 따로 적어 주세요.

## 점검 10 — 내보내기와 한글에서 열기

1. 위쪽 **내보내기**를 누릅니다. Safari가 다운로드를 물으면 허용합니다.
2. "파일" 앱 → 다운로드 폴더에 `.hwpx` 파일이 있는지 봅니다.
3. 그 파일을 한컴오피스 한글(PC·맥·아이패드 앱) 또는 [한컴독스](https://www.hancomdocs.com)에서 엽니다.

| 확인할 것 | 결과 | 본 것 |
| --- | --- | --- |
| "파일" 앱에 `.hwpx` 파일이 생긴다 | | |
| 한글에서 오류·경고 없이 열린다 | | |
| 집필에서 쓴 글이 전부 있다 | | |
| 굵게, 줄 간격 200%가 그대로다 | | |
| 표가 3줄 3칸이고 "칸1"이 들어 있다 | | |
| 한글에서 고쳐 저장한 파일을 **파일 열기**로 다시 불러올 수 있다 | | |
