## 리뷰에서 나온 후속 작업 (작업 9에서 처리)

독립 코드 리뷰(실제 엔진으로 검증)가 찾은 문제와 처리 결과.

- [x] 각주 등 컨트롤이 든 문단 뒤에 문단을 추가하면 마지막 글자가 새 문단으로 밀림 → 문단을 나누지 않고 빈 문단을 끼우도록 변경
- [x] 표 바로 뒤의 새 문단이 표 문단 안으로 들어감 → 표 문단에는 어떤 연산도 걸지 않도록 변경
- [x] 저장할 때마다 기존 줄바꿈이 빈칸으로 바뀜 → 새로 넣는 글에만 적용
- [x] Enter로 문단을 나누면 뒷부분 글자 서식이 바뀜 → 지우고 다시 치지 않고 실제로 나눔
- [x] 저장에 실패해도 서재로 나가면 글이 사라짐 → 확인 창을 띄우고 취소하면 남음
- [x] 동기화가 도중에 실패하면 문서와 화면이 어긋남 → 사본으로 되돌림
- [x] 화면을 다시 그리면 커서가 문서 맨 위로 감 → 커서 위치 복원
- [x] 쉬지 않고 쓰면 저장이 안 됨 → 15초 상한
- [x] 저장 도중에 더 고쳤는데 "저장됨" 표시 → 표시하지 않음
- [x] 표 자리 표시 옆에서 Backspace 하면 글이 표를 넘어 합쳐짐 → 그 경계에서는 지우기 차단
- [x] 개발 서버가 .git 등 숨김 파일을 내줌 → 차단
- [x] 단위 테스트의 가짜 문서가 엔진과 다름 → 규칙을 단언으로 넣고, 실제 엔진 테스트(tests/engine/) 추가
- [ ] 서비스 워커가 첫 방문에 앱을 미리 받아 두지 않음 → V2로 미룸(배포 없이는 확인 불가, SPEC 범위 밖에 기록)
- [ ] 구역이 여러 개인 문서 테스트 없음 → 시험 파일이 없어 미룸(SPEC 범위 밖에 기록)
