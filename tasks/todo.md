## 작업 1: 테스트 실행 환경 정리
**설명:** `npm test` 하나로 단위·통합 테스트가 돌게 한다. 통합 테스트는 서버를 스스로 띄우고 끈다.
**완료 조건:**
- [ ] `npm run test:unit`, `npm run test:e2e`, `npm test`가 있다
- [ ] 서버를 미리 켜지 않아도 통합 테스트가 돈다
- [ ] V0의 통합 테스트가 `tests/e2e/`로 옮겨져 그대로 통과한다
**확인:** `npm test`
**의존:** 없음
**파일:** `package.json`, `tests/e2e/*`, `tests/fixtures/sample.hwpx`, `scripts/serve.mjs`
**크기:** S

## 작업 2: 동기화 로직을 순수 함수로 분리
**설명:** 글자 차이 계산(`diffText`)과 문단 대응 계획(`planSection`)을 `js/sync.js`로 떼고 단위 테스트한다.
**완료 조건:**
- [ ] 단위 테스트가 다음을 덮는다: 앞·중간·끝 수정, 이모지, 문단 추가(맨 앞·중간·맨 끝), 삭제, 잠긴 문단, 번호가 중복·역전된 입력
- [ ] `js/engine.js`는 계획을 받아 엔진을 호출하는 일만 한다
- [ ] 기존 통합 테스트가 그대로 통과한다
**확인:** `npm test`
**의존:** 작업 1
**파일:** `js/sync.js`, `js/engine.js`, `tests/unit/sync.test.mjs`
**크기:** M
